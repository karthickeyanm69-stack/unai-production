## 🚀 Quick Overview of SamruddiSave

- **Model**: 12-Month Fixed Deposit Micro-Savings (₹1,000, ₹2,000, ₹4,000/month).
- **Incentive Structure**: 5%–6% Year-End Cash Bonus + Luxury Festival Gift Hamper at Month 12 maturity.
- **Trust & Security**: Tripartite Bank Escrow Custody Account under RBI Escrow Trustee regulations.
- **Technology Stack**: React 18, TypeScript, TailwindCSS, Supabase PostgreSQL, Vite, and Lucide Icons.
